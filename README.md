1.LIVE API INTERGRATION
The website uses the GitHub REST API and JavaScript Fetch API to retrieve and display my public GitHub repositories dynamically.
The integration includes:
a. Loading messages while data is being retrieved.
b.Dynamic display of repository information.
c.Error handling when the API request fails.

b.The contact form uses "textContent" to display messages safely.
